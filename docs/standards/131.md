# A01111005 — Производство зерновых культур

**Enbek ID:** `131`

## Описание / Область применения

Регулирование производства зерновых культур включает обеспечение применения новых инновационных методов с применением автоматизированных механизмов по обработке почвы, посадке, ухаживания за посевами, прополки, орошения, обработки различными биологическими и химическими препаратами с целью сохранности урожая, а также осуществление диагностики полей с посевами зерновых культур.

## ОКЭД
