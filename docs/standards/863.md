## Описание / Область применения

Профессиональный стандарт «Буровая бригада» применяется в нефтегазовой промышленности. Данный ПС охватывает деятельность по бурению скважин для добычи нефти и газа. Буровые бригады выполняют различные операции, связанные с бурением, обслуживанием и ремонтом скважин, обеспечивая непрерывность процесса добычи.
