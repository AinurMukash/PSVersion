## Описание / Область применения

Профессиональный стандарт «Управление отходами (управление опасными и неопасными отходами)» разработан в соответствии со статьей 5 Закона Республики Казахстан «О профессиональных квалификациях», предназначен для определения функций и формирования образовательных программ, в том числе: для обучения персонала в организациях (на специализированных предприятиях по управлению отходами), для сертификации работников и выпускников образовательных учреждений, для решения широкого круга задач в области управления персоналом, определения функций персонала на специализированных предприятиях по управлению отходами.
