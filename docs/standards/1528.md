# S96090011 — Услуги по доступности объектов инфраструктуры для населения с учетом потребностей лиц с инвалидностью и маломобильных групп

## Описание / Область применения

Профессиональный стандарт «Услуги по доступности объектов инфраструктуры для населения с учетом потребностей лиц с инвалидностью и маломобильных групп» разработан в соответствии со статьей 5 Закона Республики Казахстан «О профессиональных квалификациях», устанавливает требования к формированию образовательных программ, в том числе обучения персонала на предприятиях, работников и выпускников организаций образования и решений широкого круга задач в области предоставления услуг по доступности объектов инфраструктуры для населения.

## ОКЭД

- **Секция:** `S` — Предоставление прочих видов услуг
- **Подкласс:** `96090` — Предоставление прочих индивидуальных услуг, не включенных в другие группировки
